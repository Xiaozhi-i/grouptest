一、什么是一次函数

一次函数的标准定义是：y = kx + b。
我们可以把它通俗地理解成：y 等于一个 带 x 的数 + 一个数字。

y = kx + b

1. x 上面不能有平方、立方（有平方就是二次函数）
2. x 不能在分母（在分母就是反比例函数）
3. x 不能在根号里。

✅ y = 2x + 3     一次函数
✅ y = x - 1       一次函数
✅ y = 5x         一次函数（没有后面的数也可以）
❌ y = x2 + 2   不是
❌ y = 1x         不是

1. y = kx 叫正比例函数，它是特殊的一次函数。
2. 只要 k 不等于 0，一定是一次函数。

二、整章的核心

① k 决定：直线是上坡还是下坡。

k 正，上坡；k 负，下坡。

★ k > 0：从左往右往上爬（上坡）
★ k < 0：从左往右往下滑（下坡）

② b 决定：直线卡在 y 轴的哪里。

b > 0 交点在上方
b = 0 交点在正中间原点
b < 0 交点在下方

k 管倾斜， b 管高低。

三、一次函数 4 种图像

1. k 正、b 正 → 上坡，过 1、2、3 象限

2. k 正、b 负 → 上坡，过 1、3、4 象限

3. k 负、b 正 → 下坡，过 1、2、4 象限

4. k 负、b 负 → 下坡，过 2、3、4 象限

做题顺序：先看上下坡定 k，再看高低定 b。

四、增减性

1. k 是正数，x 变大，y 变大（越走越高）
2. k 是负数，x 变大，y 变小（越走越低）

五、求交点坐标

① 和 y 轴的交点：
公式：y = kx + b
永远交于 (0, b)

举例：y = 3x + 4
把 x = 0 代入 y = 3x + 4 得：
y = 3 × 0 + 4 = 4
∴ 直线 y = 3x + 4 与 y 轴交点坐标为：(0, 4)

② 和 x 轴的交点：
步骤永远不变：令 y = 0，解出 x。

举例：y = 2x - 4
把 y = 0 代入 y = 2x - 4 得：
2x - 4 = 0
x = 2
∴ 直线 y = 2x - 4 与 x 轴交点坐标为：(2, 0)

所有题的步骤全部一模一样。

六、求一次函数解析式

题目套路永远是： 给两个点，求式子

万能四步法（无脑套，人人会）：

设该函数的解析式为 y = kx + b
把两个点代入 y = kx + b 得：
{ kx1 + b = y1
kx2 + b = y2 }

解得：{ k = a, b = j }
∴ 直线 l 的函数解析式为 y = ax + j

题目举例：

题目：直线 l 过 (0, 1)、(2, 5)，求直线 l 的解析式（表达式）。

设该函数的解析式为 y = kx + b
把 (0, 1) 和 (2, 5) 代入 y = kx + b 得：
{ k × 0 + b = 1
k × 2 + b = 5 }

解得：{ k = 2, b = 1 }
∴ 直线 l 的函数解析式为 y = 2x + 1

“哪怕基础再差，会加减法就能拿满分。”

八、终极极简总结

1. 一次函数格式：y = kx + b
2. k 正上坡、k 负下坡
3. b 决定和 y 轴交点高低
4. 求交点：y = 0 求 x，x = 0 看 b
5. 求解析式：设、代、解、写四步走
